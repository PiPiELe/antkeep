# 蚁记 AntKeep · 开发准备

状态：已完成首个可运行的本地记录、图片存储与 ZIP 备份闭环；尚待 Android / iOS 原生构建与真机验证。
目标平台：Android、iPhone；微信小程序暂不开发。

## 产品定位

面向个人及蚂蚁爱好者的本地养殖记录工具。无需注册或登录，核心功能断网可用。
养殖记录和照片保存在设备本地，不上传养殖数据，不接入广告、行为统计或远程日志。
在线版可在配置服务地址后读取后台发布的公共资料；在线版与离线版均可匿名检查 Android 更新，且不传输养殖记录或照片。
配置在线服务并切换在线版后，可使用现有账号登录和签到。设置中的「数据推送」允许登录用户主动勾选物品栏条目并确认上传；不会自动上传蚁群、日记、照片或备份。

## 首版范围

| 模块 | 计划功能 |
| --- | --- |
| 蚁群档案 | 昵称、品种、入手日期、来源、蚁后数量、巢体类型、封面 |
| 日常记录 | 投喂、补水、观察、温湿度、换巢、繁殖、死亡、备注 |
| 成长时间线 | 按实际发生时间排列图文记录；卵、幼虫、蛹、工蚁数量支持未知及估计 |
| 快速记录 | 常用事件快捷录入；同次操作可选择多个蚁群 |
| 待办 | 养护计划、完成记录、设备本地通知 |
| 数据管理 | 存储占用、导出备份、恢复备份、换机迁移 |

首个可运行里程碑：创建蚁群 → 添加图文记录 → 查看时间线 → 导出备份 → 在空库恢复。
其后加入批量记录、成长统计与本地养护提醒。

养蚁日记支持点击卡片编辑、左滑露出删除按钮；删除前需确认。编辑回填原记录的类型、时间、备注、环境、数量与照片，保留记录 ID 和创建时间。已保存的数量按总数修改，留空表示该项未知，避免增量重复累加；保存或删除后刷新日记与种群数量图表，不改写后续记录的数量快照。

日记选中「死亡」类型后显示可选的「工蚁死亡数量」，其他类型默认隐藏；填写范围为 0～1000000 的整数。保存后在日记卡片展示，编辑时回填，改为其他类型后保存会清空该值。该字段记录本次死亡数，不自动扣减工蚁总数。数据库版本 17 新增可空字段，支持备份恢复及旧数据升级。

「分析 → 死亡分析」按蚁群展示工蚁每日死亡数，同日多条记录相加，按发生时间归属日期；空白不计入，0 保留。比较截至昨日的最近 7 日和前 7 日已记录死亡总数，展示增减、百分比和记录覆盖天数；任一周期无有效记录时显示数据不足，前期为 0 时不计算百分比。图表不使用累计死亡数，不做预测，不将漏记视为零死亡。蚁群详情在种群数量下方同样展示死亡分析卡片，复用每日折线图、周期对比及明细；新增、编辑或删除日记后随详情自动刷新，简化模式下仍可查看。

底部导航：蚁群、物品、DLC、发现、设置；养殖记录保留在蚁群详情的时间线中。
我的蚁群列表支持长按卡片上下拖动排序，顺序保存在本机，重启和刷新后保留；新增蚁群排在已排序蚁群之后。保存失败时恢复原顺序并提示重试。
蚁群顶部提供「我的蚁群 / 英灵殿」二级菜单；英灵殿暂展示纪念用途与功能规划中的说明，方向为记录死亡的蚂蚁，具体功能待定。
两个二级菜单均支持长按改名，也可在设置 → 外观与展示 → 展示模式中修改，名称为 1～12 个字符、去除首尾空白，并支持恢复默认。名称保存在本机，重启后保留；英灵殿占位页标题跟随菜单名称更新。
已购物品支持点击编辑数量，有损耗时填写剩余数量，填 0 表示已用完并保留记录。编辑框中的「删除」需二次确认，确认后从已购列表移除并清除数量、购入价和购入日期；推荐项及有效期规则保留，可再次添加。
设置 → 外观与展示 → 展示模式提供「简化模式」，默认关闭并在本机保存。开启后底部仅保留蚁群、设置，隐藏分析、个人中心与蚁群详情的百科、自动扩充入口；新建蚁群直接返回列表。档案、种群数量折线图、日常记录、提醒和备份继续可用，已有数据及增长规则不变，关闭后恢复完整展示。
「发现」提供分层的「蚂蚁百科」：热门物种的主要资料离线可查，支持名称、别名、学名与分类搜索，详情分为基础分类、体型数据、饲养信息与资料说明。非热门物种保留蚁丘公开目录索引；用户主动打开后才联网查看该物种的最新文字和图片。蚁丘内容不复制进 App，图片也不作为用户养殖媒体保存。百科参数只作资料参考，不自动修改蚁群的养护设置。
比赛、抽奖活动与养殖工具入口仍展示敬请期待，后续逐步开放。
蚁群详情的品种旁提供「百科」入口：名称、别名或学名精确匹配时直达对应详情；未收录时带入品种名称搜索，显示无匹配提示；未填写品种时不显示入口。

## 已验证的技术实现

- Flutter / Dart：共享 Android 与 iOS 界面及业务逻辑；当前 SDK 为 Flutter 3.47.5 / Dart 3.13.4。
- SQLite：保存蚁群与记录，外键约束开启；新增记录和蚁群更新时间在同一事务中完成。
- 应用私有目录：照片先复制到应用目录，再以相对路径保存；不依赖相册原文件。
- ZIP 备份：包含版本化清单、数据库行和照片文件；恢复前验证格式、版本、表结构、记录引用和附件完整性。
- Android：清单中关闭系统备份；iOS：持久化目录通过原生通道申请排除 iCloud 备份。
- 将持久化、图片、备份与界面分离，保持后续提醒与统计可独立加入。
- 在线账号、签到和物品推送使用 `ANTKEEP_API_BASE_URL` 对应的 `/api/app/` 接口；未配置或离线时不能推送。Android 正式清单声明 INTERNET 权限。

## 发育模式与数量增量

- 新建和编辑蚁群时选择「卵 → 幼 → 茧 → 工」或「卵 → 幼 → 工」，并可填写初始幼虫数量。自动扩充的发育路径统一读取蚁群档案，页面不再单独选择路径；启停和周期设置保留。
- 新增养护记录的「增量」默认开启：卵增加量直接加卵，幼虫增加量同时扣卵，茧增加量同时扣幼虫，工蚁增加量根据模式扣茧或幼虫。同次填写多阶段时，按各阶段增加量与转出量一起计算。关闭增量后填写当前总数。
- 增量在数据库事务中按记录发生时间前的数量换算成总数，来源和目标同时写入。未填写且未发生转出的阶段不写新数量；补记过去不改写之后已有的总数快照。
- 相关数量未知或转化后小于零时拒绝保存，需先用总数模式校正；未知不会按零计算。不经过茧时，增量记录不接受茧增加值，总数模式仍可校正历史茧数量。
- 自动扩充新增幼虫净增长，留空时沿发育路径扣减，明确填写仍按每周期净增长处理。旧档案的幼虫数量保留未知，需补充后才能估算涉及幼虫的转化；旧路径按是否经过茧保留。数据库版本 16 新增幼虫数量和发育模式字段，备份随档案保存，旧备份可恢复。

## 数据原则与恢复安全

1. 未知数量与零分开保存；估计值不能伪装成精确计数。
2. 事件发生时间与创建、修改时间分开，支持补记过去的养殖事件。
3. 每条记录使用稳定 ID，归属明确的蚁群；蚁群归档应保留历史记录。
4. 一次批量记录应在数据库事务中完成，避免仅部分蚁群保存成功。
5. 照片必须复制成功后才能形成有效引用；处理应用重启及磁盘空间不足。
6. 备份包含格式版本、数据清单及引用照片；Android / iOS 使用同一可移植格式。
7. 恢复前弹窗选择增量或覆盖：增量仅补入缺失 ID 的蚁群、养护记录、饲料记录和物品；相同 ID 及同分组同名物品保留本机内容，不累加数量。导入照片使用独立文件名，避免覆盖本机照片；重复增量导入不增加重复记录。覆盖恢复沿用整库替换，旧备份缺少物品表时保留本机物品。两种方式均保留恢复前的回退副本，不做跨设备自动同步。
8. 恢复前先校验版本、字段、关联关系、附件完整性、路径与体积限制。
9. 先在临时位置完成准备，验证成功后再切换；失败不能破坏现有记录。
10. 覆盖现有数据需要应用内明确提示，并在覆盖前保留本地回退副本。
11. 手动导出的备份属于用户文件；应用不自动发送到网盘或其他服务。
12. 平台系统云备份需明确排除：Android 检查备份及设备迁移规则，
    iOS 检查持久化目录的备份排除属性。具体效果需要真机验证。
13. 本地保存不等于已做数据库加密；首版不宣称额外的应用级加密能力。
14. 卸载、设备损坏可能导致本地数据丢失；提供清楚的备份提醒与恢复入口。

## 在线版、应用更新与个人中心

- 设置 → 帮助与反馈 → 交流群二维码：内置微信、抖音群原图，离线和简化模式均可查看；支持点击放大、双指缩放及抖音群号选择复制，可截图后在对应应用扫码。当前二维码标注有效期至 2026 年 10 月 8 日，到期后需替换图片资源。

当前状态：公共资料和 Android 更新策略可通过 `ANTKEEP_API_BASE_URL` 匿名读取；在线版通过同一服务的 `/api/app/` 接口注册、登录、签到及主动推送所选物品。未配置或切换离线时不能推送。旧 `AccountController` 保持默认关闭，数据推送不使用其 `/api/account/` 协议。

- App 启动时，无论在线版还是离线版，均匿名检查 `GET /api/public/app-update/android`，设置中也可手动检查；版本号固定为 `major.minor.patch`。离线版发现新版本时提示一次，可稍后更新；自动检查失败时静默忽略，不阻塞本地功能。低于后台最低版本时只停止在线功能，用户仍可切换离线版使用本地记录、照片与备份。切换资料模式会重新检查，其他偏好变更不会触发检查。
- 更新页由后台提供 HTTPS 下载地址；App 仅打开外部页面，不下载、校验或安装 APK，也不上传设备或养殖数据。
- 更新弹窗展示后台已发布的「更新说明」（`releaseNotes`），保留换行并支持长内容滚动。后台上传并发布 APK 后，弹窗同时展示接口 `apk.filename` 与 `apk.sizeBytes` 对应的文件名和大小；旧策略没有 APK 信息时仍可正常提示、跳转更新。更新说明需在后台保存草稿并发布后才会供 App 获取。
- 更新说明支持直接填写 `https://example.com/details`、`http://example.com/details`，或 `[查看详情](https://example.com/details)`。链接可点击并交由外部浏览器/系统应用打开，打开失败会在弹窗内提示；不加载远程图片或内嵌网页。

- 入口：设置 → 在线服务 → 登录与签到。提供用户名/密码注册登录、签到和退出登录，不提供头像。
- 签到以服务端北京时间（Asia/Shanghai）为准，每天一次；展示累计、连续天数，跨设备登录同一账号同步。
- 仅服务器确认成功后更新签到状态；网络失败可重试，重复请求不会重复计数。
- 会话仅留在 App 进程内存，关闭 App 或切回离线版后需重新登录；不将密码或令牌写入本地数据库、浏览器本地存储或导出备份。
- 构建时使用 `--dart-define=ANTKEEP_API_BASE_URL=https://在线服务域名` 指定服务根地址；未配置时个人中心显示暂未开放，不伪造登录或签到。
- 服务代码位于相邻 `antkeep-content-admin` 项目，接口与部署说明见其 README；本次源码实现不代表公网服务已部署。

## 物品栏数据推送

设置 → 数据管理 → 数据推送：进入后选择物品（已购、未购均可选），确认后发送当前物品快照到 B 端。单次 1–200 条，默认不勾选。快照含本地物品 ID、名称、分组、购买状态、数量、购入价（分）、购入/创建日期及有效期字段；不修改本地数据。

每日限额按登录账号及服务端北京时间（Asia/Shanghai）自然日计算，成功写入后占用当日一次额度，跨设备和并发请求共享限制。零点后刷新状态即可再次推送。失败可重试；网络响应丢失时查询服务端状态确认结果，不自动重发。B 端「数据推送」可按用户名搜索、分页查看历史快照。发布时需先部署 B 端及 V5 数据库迁移，再发布 App。

## 设置页分组

设置首页仅保留六个入口并显示当前状态：外观与展示、在线服务、养护提醒、数据管理、帮助与反馈、关于与更新。主题、外观模式、简化模式、菜单名称和新手提示放入外观与展示；资料模式、账号登录、签到及公共资料更新归入在线服务。备份导出、恢复、撤销恢复和数据推送统一归入数据管理。使用指南与交流群归入帮助与反馈，安装版本和检查更新归入关于与更新。二级页面有独立返回入口，偏好变化实时生效，原有保存及恢复确认流程保留。

## 本地分享图片

蚁群详情右上角「生成分享图」提供蚁群名片、日记卡片、成长对比、养蚁月报；日记旁的分享按钮直接选中该条日记。四种卡片共用本地预览，提供浅色手账 / 深色摄影、选图和裁切位置、分享文字（最多 600 字，不修改日记）、数量 / 日期 / 天数 / 温湿度 / 文字显示开关。月报按单个蚁群及所选月份生成，可选最多四张照片；对比可选两个日期及对应照片。

数量使用截至所选日期各阶段最近已知的总数，不将未知视为 0；自动扩充记录的数量标注估算，后续实际记录可校正对应阶段。月报区分人工日记与自动估算，按实际发生时间统计记录天数，以月初前的最近已知数量（当月入手则为初始数量）与月末截至数量比较；无记录和端点未知分别提示。月报趋势仅绘制当月有工蚁数量的记录，不使用预测。图片不包含来源、价格或账号信息。

输出 PNG 宽度为 1080 像素，高度随内容变化。Android 10 及以上保存到系统相册 Pictures/AntKeep；更早 Android 通过系统文件选择器保存。iOS 请求添加照片权限后写入相册，拒绝或失败有明确提示，可使用「另存为文件」。生成过程不需要登录或联网，不上传任何照片或记录，也不自动调用社交应用。原生相册权限与保存结果仍需两端真机验收。
