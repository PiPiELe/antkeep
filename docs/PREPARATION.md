# 蚁记 AntKeep · 开发准备

状态：已完成首个可运行的本地记录、图片存储与 ZIP 备份闭环；尚待 Android / iOS 原生构建与真机验证。
目标平台：Android、iPhone；微信小程序暂不开发。

## 产品定位

面向个人及蚂蚁爱好者的本地养殖记录工具。无需注册或登录，核心功能断网可用。
养殖记录和照片保存在设备本地，不上传养殖数据，不接入广告、行为统计或远程日志。
在线版可在配置服务地址后读取后台发布的公共资料；该请求不传输养殖记录或照片。
账号与签到仍未开放，相关请求保持关闭；后续明确启用后，仅同步用户名、昵称和签到记录，养殖数据不随账号同步。

## 首版范围

| 模块 | 计划功能 |
| --- | --- |
| 蚁群档案 | 昵称、品种、入手日期、来源、蚁后数量、巢体类型、封面 |
| 日常记录 | 投喂、补水、观察、温湿度、换巢、繁殖、死亡、备注 |
| 成长时间线 | 按实际发生时间排列图文记录；卵、幼虫、蛹、工蚁数量支持未知及估计 |
| 快速记录 | 常用事件快捷录入；同次操作可选择多个蚁群 |
| 待办 | 养护计划、完成记录、设备本地通知 |
| 数据管理 | 存储占用、导出备份、恢复备份、换机迁移 |

首个可运行里程碑：创建蚁群 → 添加图文记录 → 查看时间线 → 导出备份 → 在空库恢复。
其后加入批量记录、成长统计与本地养护提醒。

底部导航：蚁群、物品、DLC、发现、设置；养殖记录保留在蚁群详情的时间线中。
「发现」提供分层的「蚂蚁百科」：热门物种的主要资料离线可查，支持名称、别名、学名与分类搜索，详情分为基础分类、体型数据、饲养信息与资料说明。非热门物种保留蚁丘公开目录索引；用户主动打开后才联网查看该物种的最新文字和图片。蚁丘内容不复制进 App，图片也不作为用户养殖媒体保存。百科参数只作资料参考，不自动修改蚁群的养护设置。
比赛、抽奖活动与养殖工具入口仍展示敬请期待，后续逐步开放。
蚁群详情的品种旁提供「百科」入口：名称、别名或学名精确匹配时直达对应详情；未收录时带入品种名称搜索，显示无匹配提示；未填写品种时不显示入口。

## 已验证的技术实现

- Flutter / Dart：共享 Android 与 iOS 界面及业务逻辑；当前 SDK 为 Flutter 3.47.5 / Dart 3.13.4。
- SQLite：保存蚁群与记录，外键约束开启；新增记录和蚁群更新时间在同一事务中完成。
- 应用私有目录：照片先复制到应用目录，再以相对路径保存；不依赖相册原文件。
- ZIP 备份：包含版本化清单、数据库行和照片文件；恢复前验证格式、版本、表结构、记录引用和附件完整性。
- Android：清单中关闭系统备份；iOS：持久化目录通过原生通道申请排除 iCloud 备份。
- 将持久化、图片、备份与界面分离，保持后续提醒与统计可独立加入。
- 账号与签到请求默认关闭，即使配置服务地址也不会联网；Android 正式清单不声明 INTERNET 权限。

## 数据原则与恢复安全

1. 未知数量与零分开保存；估计值不能伪装成精确计数。
2. 事件发生时间与创建、修改时间分开，支持补记过去的养殖事件。
3. 每条记录使用稳定 ID，归属明确的蚁群；蚁群归档应保留历史记录。
4. 一次批量记录应在数据库事务中完成，避免仅部分蚁群保存成功。
5. 照片必须复制成功后才能形成有效引用；处理应用重启及磁盘空间不足。
6. 备份包含格式版本、数据清单及引用照片；Android / iOS 使用同一可移植格式。
7. 首版恢复采用整库恢复，不做跨设备自动同步或复杂合并。
8. 恢复前先校验版本、字段、关联关系、附件完整性、路径与体积限制。
9. 先在临时位置完成准备，验证成功后再切换；失败不能破坏现有记录。
10. 覆盖现有数据需要应用内明确提示，并在覆盖前保留本地回退副本。
11. 手动导出的备份属于用户文件；应用不自动发送到网盘或其他服务。
12. 平台系统云备份需明确排除：Android 检查备份及设备迁移规则，
    iOS 检查持久化目录的备份排除属性。具体效果需要真机验证。
13. 本地保存不等于已做数据库加密；首版不宣称额外的应用级加密能力。
14. 卸载、设备损坏可能导致本地数据丢失；提供清楚的备份提醒与恢复入口。

## 在线版、应用更新与个人中心

当前状态：公共资料可通过 `ANTKEEP_API_BASE_URL` 匿名读取；未配置时不发起有效网络请求。小米版首次启动还会通过同一 HTTPS 地址读取内容后台已发布的隐私政策；小米版不提供账号入口和运行后的更新提示。

- App 仅在用户选择在线版时检查 `GET /api/public/app-update/android`；版本号固定为 `major.minor.patch`。低于后台最低版本时只停止在线功能，用户仍可切换离线版使用本地记录、照片与备份。
- 更新页由后台提供 HTTPS 下载地址；App 仅打开外部页面，不下载、校验或安装 APK，也不上传设备或养殖数据。

- 入口：设置 → 在线版 → 个人中心与签到。提供用户名/密码注册登录、昵称修改、签到和退出登录，不提供头像。
- 签到以服务端北京时间（Asia/Shanghai）为准，每天一次；展示累计、连续天数和最近 31 次签到，跨设备登录同一账号同步。
- 仅服务器确认成功后更新签到状态；网络失败可重试，重复请求不会重复计数。
- 会话仅留在 App 进程内存，关闭 App 或切回离线版后需重新登录；不将密码或令牌写入本地数据库、浏览器本地存储或导出备份。
- 构建时使用 `--dart-define=ANTKEEP_ACCOUNT_BASE_URL=https://账号服务域名` 指定服务根地址；未配置时个人中心显示暂未开放，不伪造登录或签到。
- 服务代码位于相邻 `antkeep-content-admin` 项目，接口与部署说明见其 README；本次源码实现不代表公网服务已部署。
