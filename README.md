# 蚁记 AntKeep

面向 Android 与 iPhone 的本地优先蚂蚁养殖记录工具，使用 Flutter / Dart 开发。核心养殖功能无需账号、断网可用，档案、日记、照片和备份默认保存在设备；可选在线服务提供公共资料、账号签到、物品快照推送和蚁友比赛。项目不接入广告或行为统计。

## 当前功能

- **蚁群与日记**：蚁群建档、拖动排序、图文时间线、历史记录编辑与删除，支持投喂、补水、观察、温湿度和死亡记录。数量可按增量或总数录入，区分未知、零和估算值。
- **数量与分析**：种群数量曲线、自动扩充估算、增长预测、工蚁死亡分析和消费分析；人工总数记录可校正后续估算。
- **养护与巢体**：投喂、补水、清洁的周期待办及本地每日提醒，完成待办可生成日记；巢体履历记录使用过的巢体类型、名称、启用日期和备注，标记当前巢体后同步更新蚁群档案。每个蚁群可记录越冬开始、计划结束、实际结束和备注，保留历次周期。
- **婚飞观察与天气**：婚飞日期、地点、蚁种、数量和备注保存在本机；用户手动搜索城市后，可查看 Open-Meteo 七日天气和基于页面所示阈值的观察提示。提示仅是天气参考，不预测具体蚁种的婚飞。
- 天气查询使用 Open-Meteo 免费接口，适用于非商业使用，页面标注数据来源和 CC BY 4.0 许可；如将应用用于商业产品，发布前需改用有商业授权的接口。
- **物品**：管理已购物品的数量、价格、购入日期和有效期。
- **英灵殿**：蚁后、工蚁、幼体纪念及整群归档，保留历史档案与日记，支持恢复归档蚁群。
- **本地分享**：蚁群名片、日记卡片、成长对比、养蚁月报和纪念分享图，先预览再保存图片或调用系统分享。
- **资料与外观**：热门物种离线百科、其他物种的在线目录入口，新手引导、多种主题与字体颜色、浅色 / 深色 / 跟随系统外观、简化模式和日记展示设置。
- **备份恢复**：ZIP 导出、增量补入、覆盖恢复及恢复前回退副本，包含养殖记录、照片、物品和纪念数据。
- 巢体履历、越冬周期和婚飞观察也随 ZIP 备份导出与恢复；新备份格式为 v4，仍可导入 v1 / v2 / v3 备份。旧档案已有巢体类型会转为一条当前巢体记录，启用日期保持未知。

首次打开先选择主题和外观，再选择养蚁经验。完成后不再重复引导；设置中可随时调整。外观和展示偏好仅保存在本机，不随养殖数据备份导入或覆盖。蚁群列表提供批量养护记录入口，可逐群确认投喂、补水或清洁。

## 可选在线服务与数据边界

构建时通过 `--dart-define=ANTKEEP_API_BASE_URL=https://服务域名` 配置 Java 服务地址。在线版支持注册、登录、每日签到、已发布公共资料和启动公告；登录会话仅保存在进程内存中，关闭 App 或切回离线版后需重新登录。

设置 → 数据管理 → 数据推送：登录后输入具有上传用途的码值，主动勾选并确认提交物品快照。每个账号每天按北京时间限成功推送一次，成功后消耗码值一次使用次数，后台可查看历史快照。

蚁友比赛支持登录后发起比赛、报名和每日主动提交数量快照；发起的比赛名称需后台审核，报名需同意当前比赛免责声明。报名时仅上传所选蚁群档案、数量快照和所选图片，日记及备份不上传。支持生成比赛宣传和榜单海报，分享榜单仅展示随机参赛 ID、虫量和分值。

App 不自动同步本地养殖数据；未选择推送物品或参加比赛时，养殖记录和媒体保留在设备。

## 本地开发

需要与 `pubspec.yaml` 兼容的 Flutter SDK（Dart `^3.13.4`）及对应平台工具链。

```sh
flutter pub get
flutter run
```

可使用 `flutter analyze` 和 `flutter test` 检查源码。Android / iOS 原生构建、通知、相册保存及备份恢复的真机验收需单独执行，源码实现不代表商店发布完成。

开发与数据规则见 [docs/PREPARATION.md](docs/PREPARATION.md)。Android APK 的 GitHub Release 发布配置、签名 Secrets 和固定下载链接见 [docs/GITHUB_RELEASE.md](docs/GITHUB_RELEASE.md)；在线服务交付见 [docs/SERVER_DELIVERY.md](docs/SERVER_DELIVERY.md)。

## 备份限制

备份导入与导出使用相同限制：最多 1999 张照片，ZIP 最大 512 MB，单个附件最大
64 MB，清单最大 8 MB，解压后总量最大 768 MB。超限时导出会报错，不生成无法恢复的备份。
恢复会先校验记录字段、日期和关联关系；无效备份不会覆盖现有数据或上次回退副本。
Android / iOS 备份使用临时文件与逐附件流式处理，按当前可用内存选择 64 KB～1 MB
的读取缓冲区，保持单附件串行处理；文件容量上限不随手机配置变化。压缩与解压在后台
isolate 执行，照片及回退副本保存在磁盘，不整包传输到原生保存接口。每个恢复附件均校验
实际解压大小和 CRC；空间不足时在替换前报错，数据库写入失败时恢复照片和此前的回退副本。
内存或磁盘信息不可用时使用保守缓冲区并保留文件 I/O 错误处理。Web 预览保留原有内存式实现。
临时文件正常结束后清理；手机强制结束进程后的自动恢复不在本次保证范围内。
