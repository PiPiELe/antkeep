# 蚁记 AntKeep

面向 Android 与 iPhone 的本地优先蚂蚁养殖记录工具。蚁群、养殖记录和照片只存于设备；首版不需要账号、服务器、广告或云同步。

当前支持创建蚁群、图文日记与时间线、成长统计、本地每日养护提醒和 ZIP 备份恢复。每窝蚁群可设置投喂、补水、清洁的周期待办；到期事项显示在蚁群列表，完成时创建对应日记并从完成当天计算下次日期，也可顺延到明天。投喂日记可选填食物、投喂量、进食情况和是否有剩余食物。待办与投喂结果随备份保存；批量记录仍待后续实现。

首次打开先预览并选择五种主题色及外观模式（跟随系统、浅色、深色），再选择养蚁经验：新手查看建档、记录和备份提示，老玩家直接开始使用。完成后不再重复引导；设置中可随时调整主题色、外观模式和新手注意事项。新安装默认跟随系统。未完成引导时关闭应用，下次仍会显示引导。旧版本升级后若尚无完成标记，也会显示一次，并保留原来的深色模式设置。这些偏好仅保存在本机，不随养殖数据备份导入或覆盖。

开发说明见 [docs/PREPARATION.md](docs/PREPARATION.md)。

Android APK 通过 GitHub Release 分发；发布配置、签名 Secrets 和固定下载链接见 [docs/GITHUB_RELEASE.md](docs/GITHUB_RELEASE.md)。

备份导入与导出使用相同限制：最多 1999 张照片，ZIP 最大 512 MB，单个附件最大
64 MB，清单最大 8 MB，解压后总量最大 768 MB。超限时导出会报错，不生成无法恢复的备份。
恢复会先校验记录字段、日期和关联关系；无效备份不会覆盖现有数据或上次回退副本。
Android / iOS 备份使用临时文件与逐附件流式处理，按当前可用内存选择 64 KB～1 MB
的读取缓冲区，保持单附件串行处理；文件容量上限不随手机配置变化。压缩与解压在后台
isolate 执行，照片及回退副本保存在磁盘，不整包传输到原生保存接口。每个恢复附件均校验
实际解压大小和 CRC；空间不足时在替换前报错，数据库写入失败时恢复照片和此前的回退副本。
内存或磁盘信息不可用时使用保守缓冲区并保留文件 I/O 错误处理。Web 预览保留原有内存式实现。
临时文件正常结束后清理；手机强制结束进程后的自动恢复不在本次保证范围内。

物品栏支持可选的数据推送：设置 → 数据管理 → 数据推送，在线登录后勾选并确认上传。每个账号每天北京时间限成功推送一次，B 端可查看历史快照；其余本地记录和媒体不随此功能上传。
