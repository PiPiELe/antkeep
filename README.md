# 蚁记 AntKeep

面向 Android 与 iPhone 的本地优先蚂蚁养殖记录工具。蚁群、养殖记录和照片只存于设备；本地功能免登录；可选在线模式支持账号、签到和公共资料，不上传养殖数据，不接入广告或云同步。

当前已完成首个可运行闭环：创建蚁群、添加带照片的记录、查看时间线、导出 ZIP 备份，以及覆盖式恢复备份。待办提醒、批量记录和成长统计属于下一阶段。

首次打开先预览并选择五种主题色及外观模式（跟随系统、浅色、深色），再选择养蚁经验：新手查看建档、记录和备份提示，老玩家直接开始使用。完成后不再重复引导；设置中可随时调整主题色、外观模式和新手注意事项。新安装默认跟随系统。未完成引导时关闭应用，下次仍会显示引导。旧版本升级后若尚无完成标记，也会显示一次，并保留原来的深色模式设置。这些偏好仅保存在本机，不随养殖数据备份导入或覆盖。

开发说明见 [docs/PREPARATION.md](docs/PREPARATION.md)。

## 在线功能

设置中可切换在线/离线模式。在线游客可读取公共物品模板与新手资料；用户名密码登录后可每日签到，
查看连续和累计天数（服务端北京时间）。退出或切换账号不修改本机蚁群、物品、照片或记录。
从模板新增物品仅预填名称与有效期；分类、单位作为模板提示，保留手动填写。

```sh
flutter pub get
flutter run --dart-define=ANTKEEP_API_BASE_URL=https://your-antkeep-service.example
```

没有配置服务地址时仍可使用本地功能，在线入口会提示未配置。正式移动端仅连接 HTTPS。
Android 明确关闭明文 HTTP，iOS 保持 ATS；本地联调可使用可信 HTTPS 代理。
Web 本地预览可用 `--web-port=18789`，并在服务端 `ANTKEEP_APP_ORIGINS` 配置精确 Origin。
仅 Debug Web/桌面网络层允许 localhost/127.0.0.1/Android 模拟器回环 HTTP；不放宽正式包网络策略。

App 会话保存在系统安全存储中；Web 仅保存在内存，刷新页面后重新登录。公共内容缓存独立存储。
两者均不进入养殖 SQLite、图片目录或手动 ZIP 备份。离线模式始终使用内置资料且停止业务请求；
重新进入在线模式会验证保留的会话。服务器不可用时使用有效缓存或内置资料，不影响本地记录。
网络不可用时退出会清理本机身份并提示服务端会话未确认撤销，到期后失效。

注册不验证邮箱/手机，首版没有密码找回；请妥善保存账号密码。
服务端启动、管理员初始化与迁移见 Java 服务仓库 README。

验证：`flutter analyze`、`flutter test`、`flutter build web`；Android/iOS 构建与真机测试需要对应 SDK。
