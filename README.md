# 蚁记 AntKeep

面向 Android 与 iPhone 的本地优先蚂蚁养殖记录工具。蚁群、养殖记录和照片只存于设备；首版不需要账号、服务器、广告或云同步。

当前已完成首个可运行闭环：创建蚁群、添加带照片的记录、查看时间线、导出 ZIP 备份，以及覆盖式恢复备份。待办提醒、批量记录和成长统计属于下一阶段。

首次打开先预览并选择五种主题色及外观模式（跟随系统、浅色、深色），再选择养蚁经验：新手查看建档、记录和备份提示，老玩家直接开始使用。完成后不再重复引导；设置中可随时调整主题色、外观模式和新手注意事项。新安装默认跟随系统。未完成引导时关闭应用，下次仍会显示引导。旧版本升级后若尚无完成标记，也会显示一次，并保留原来的深色模式设置。这些偏好仅保存在本机，不随养殖数据备份导入或覆盖。

开发说明见 [docs/PREPARATION.md](docs/PREPARATION.md)。

Android APK 通过 GitHub Release 分发；发布配置、签名 Secrets 和固定下载链接见 [docs/GITHUB_RELEASE.md](docs/GITHUB_RELEASE.md)。

备份导入与导出使用相同限制：最多 499 张照片，ZIP 最大 128 MB，单个附件最大
24 MB，清单最大 1 MB，解压后总量最大 192 MB。超限时导出会报错，不生成无法恢复的备份。
恢复会先校验记录字段、日期和关联关系；无效备份不会覆盖现有数据或上次回退副本。
